Note: This repository provides a simplified, pedagogical NumPy demonstrator to illustrate the core mathematical concepts (e.g., physical regularization and structural graph projections) of the PC-BRL-Net framework. It is intended for conceptual understanding and educational purposes. The comprehensive PyTorch pipeline (including full PPO training and Bayesian Optimization) used for the large-scale empirical results in the paper is highly deeply integrated with our internal hardware deployment framework and is currently not included in this minimal demonstrator.
